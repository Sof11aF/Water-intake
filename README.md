# 💧 Water Intake Tracker

A lightweight Progressive Web App (PWA) for tracking daily water consumption, monitoring hydration goals, and building healthy habits.

## Features

### Daily Tracking

* Quick-add buttons for common drink amounts (150 ml, 250 ml, 500 ml)
* Custom water intake entry
* Real-time hydration total
* Animated water bottle visualization
* Undo individual entries

### History & Analytics

* 7-day hydration history
* Daily intake chart
* Average water consumption statistics
* Goal completion tracking

### Goals & Streaks

* Customizable daily hydration goal
* Progress bar visualization
* Consecutive-day streak tracking
* Goal achievement statistics

### Mobile App Experience

* Installable as a Progressive Web App (PWA)
* Works on iPhone and Android
* Full-screen app experience
* Home screen icon support
* Offline functionality through Service Worker

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Chart.js
* Local Storage API
* Progressive Web App (PWA)

## Installation

### Run Locally

1. Clone the repository

```bash
git clone https://github.com/Sof11aF/Water-intake.git
```

2. Open `index.html` in a browser

or

3. Use a local server

```bash
python -m http.server 8000
```

## Deploy with GitHub Pages

1. Push the repository to GitHub
2. Go to **Settings → Pages**
3. Select:

   * Source: Deploy from a branch
   * Branch: main
   * Folder: / (root)
4. Save

The app will be available at:

```text
https://sof11af.github.io/Water-intake/
```

## Install on Mobile

### iPhone

1. Open the app in Safari
2. Tap Share
3. Select "Add to Home Screen"
4. Tap Add

### Android

1. Open the app in Chrome, Edge, Brave, or Samsung Internet
2. Tap "Install App" or "Add to Home Screen"
3. Confirm installation

## Data Storage

All data is stored locally on the device using browser Local Storage.

No accounts, servers, or external databases are required.
